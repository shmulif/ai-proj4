When you’re doing very bad, it makes sense it’d be yellow because it’s still worth it to try for more points because otherwise you’ll lose anyways. 
When your points start getting a little better, the reason it starts shading green is because you’re doing okay enough that you don’t need to try for as much so it’s not worth it to try for so high because you can lose it all. 
The jump is because at that point now you have enough points that you can afford to lose all of them again so you might as well try for more points.

- When it’s very low, you have to take the risk
- When you’re doing okay it’s best not to take the risk
- When you’re doing better, now you can afford the risk
